# Проверка раздела «Гайд и правила» Evi

## Desktop 1280×1800

Новый блок визуально продолжает красно-чёрную zine-систему: большая заголовочная типографика, чёрные карточки, красные контуры и заметный прайс-блок. Карточки читаются и формируют понятную иерархию: Follow, формат канала, соцсети, друзья, порядок в чате, прайс.

## Mobile 375×2400

Секция переходит в одну колонку. Заголовок и вводный текст помещаются по ширине, карточки не выходят за границы экрана, кнопки и текст остаются читаемыми. На кадре виден переход к первой карточке Follow; остальные правила продолжаются ниже по странице, что ожидаемо для длинного справочного раздела.

## Итог

TypeScript и production build проходят. Критичного горизонтального переполнения в рендере не обнаружено. Раздел можно публиковать после переноса новой сборки в корень GitHub Pages.
